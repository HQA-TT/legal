## GitHub Pages

In repository Settings → Pages, choose Deploy from a branch → main → / (root), then Save. The `.nojekyll` file serves the HTML directly.

Expected public URLs after Pages is enabled:

- https://hqa-tt.github.io/legal/novalira/privacy.html

## Maintaining the policies

The Novalira pages reflect its current implementation: local favorites/history/progress and preferences; TikDrama searches and streaming requests; Google AdMob and mediation libraries; Firebase Analytics and Remote Config; support correspondence; Android backup possibility. NijPath has separate browser-specific pages in `nijpath/`.

Review whenever providers, consent controls, content rights, age rating, monetization, or data practices change. The policies do not claim that consent has been obtained by merely installing the app, that local deletion removes provider records, or that every bundled mediation SDK serves every user. They do not promise offline viewing, cloud synchronization, or exclusive content.

Sources used for provider disclosures and rights references are linked within the Privacy Policy. Keep operator/contact details current and maintain stable URLs.
